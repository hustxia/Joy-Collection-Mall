# 悦集商城（Joy Collection Mall）项目介绍

> 仓库：<https://gitee.com/hustxiayuhong/joy-collection-mall.git>
> 文档更新时间：2026-10-30（数据口径见文末）

## 一、项目定位

**悦集商城**是一套前后端分离、三端一体（H5 商城 / PC 商城 / 运营后台）的完整电商演示系统：从逛商品、加购物车、领券下单、模拟支付，到申请售后、商家审核、退款回补库存，**购物的完整闭环全部可跑通**。项目同时是一套规范的工程实践样板——分层清晰、状态机幂等、有单元测试 + HTTP 冒烟 + UI 走查三层验证。

## 二、核心特性

1. **三端一体，一套后端**
   - H5 商城（Vant 4 移动端体验）、PC 商城（Element UI 大屏体验）、运营后台（Element UI）共用同一个后端服务，接口按「C 端 / 管理端」分包。
2. **售后闭环（V4）**
   - 退货退款 / 仅退款双类型，七态状态机（待审核 → 审核通过/拒绝 → 已退款 / 已关闭 / 用户撤销）。
   - 条件 UPDATE 幂等闸门：重复审核、重复退款直接返回失败，**库存绝不二次回补**；`SELECT ... FOR UPDATE` 行锁防止一订单并发多售后。
   - 退货退款自动回补库存、回减销量；仅退款不动库存。
3. **营销与会员**
   - 商品 + SKU 双层模型、优惠券（领取/使用/退回）、会员体系、收货地址、订单日志全链路留痕。
4. **开箱即用的演示数据**
   - 演示会员、商品、订单、售后样本全部随 SQL 脚本幂等导入，克隆即可体验。

## 三、技术栈

| 层 | 技术 | 说明 |
|---|---|---|
| 后端 | Spring Boot 3.2.5 + MyBatis-Plus 3.5.5 + MySQL 8 | 单体服务，端口 8431 |
| 认证 | JWT（双链路） | C 端会员 token 与后台 sys token 分离鉴权；密码 BCrypt |
| ID 策略 | 雪花 ID（Long → String 下发） | 前端一律按字符串处理，避免 JS 精度丢失 |
| H5 商城 | Vue 3.5 + Vant 4.9 + Pinia + Vite | 端口 9531 |
| PC 商城 | Vue 2.7 + Element UI 2.15 | 端口 9432 |
| 运营后台 | Vue 2.7 + Element UI 2.15（vue-cli） | 端口 9431，菜单/路由/权限由 `sys_menu` + `v-hasPermi` 驱动 |

## 四、功能清单

**C 端（H5 / PC 同构）**：首页（轮播/推荐）· 商品分类 · 商品列表/详情（多图/SKU 规格）· 购物车 · 优惠券中心/我的券 · 下单确认（券抵扣）· 模拟支付 · 订单列表/详情（含售后角标与进度卡）· 售后申请/列表/详情（凭证图片上传）· 个人中心 · 收货地址

**运营后台（12 个业务模块）**：商品 · SKU · 分类 · 品牌 · 轮播 · 会员 · 订单 · 订单日志 · 售后管理（**审核弹窗 + 确认退款二次确认**）· 优惠券 · 券领取记录 · 收货地址，另有系统字典管理。

## 五、架构与数据模型

```
mall-shop(H5)   mall-pc(PC)   mall-web(后台)
     │  9531        │  9432        │  9431
     └──────────────┼──────────────┘
                    ▼  HTTP + JWT
          mall-server (Spring Boot 3, 8431)
           ├── controller/shop/   C 端接口（Auth/Home/Cart/Goods/Coupon/
           │                      Order/Pay/Refund/Upload/Address）
           ├── controller/        管理端接口（12 个 Mall*Controller + SysDict）
           ├── service/           业务逻辑（订单状态机、售后状态机、库存联动）
           └── mapper/ + MySQL    14 张 mall_* 业务表 + sys_* 权限表
```

业务表（14 张）：`mall_goods / mall_sku / mall_category / mall_brand / mall_banner / mall_member / mall_cart / mall_order / mall_order_item / mall_order_log / mall_coupon / mall_coupon_record / mall_address / mall_refund`。

## 七、快速开始

环境要求：JDK 21、Maven 3.6+、Node 18+、MySQL 8.0。

```bash
# 1. 建库并导入基线快照（表结构 + 演示数据，75 张表）
mysql -uroot -p -e "CREATE DATABASE IF NOT EXISTS yueji_mall DEFAULT CHARACTER SET utf8mb4"
mysql -uroot -p --default-character-set=utf8mb4 yueji_mall < audit/yueji_mall-dump.sql

# 2. 启动后端（端口 8431）
cd be/mall-server && mvn spring-boot:run

# 3. 分别启动三端
cd fe/mall-shop && npm i && npm run dev     # H5    http://localhost:9531
cd fe/mall-pc    && npm i && npm run serve  # PC    http://localhost:9432
cd fe/mall-web   && npm i && npm run serve  # 后台  http://localhost:9431
```

**演示账号**
- C 端会员：`13800000001` ~ `13800000006`，密码统一 `123456`
- 运营后台：`admin` / `admin123`（登录需算术验证码）
