# mall 接口分包（三端 ↔ 后端归属）

> 核对时间：2026-10-28（2026-10-29 修订：旧 H5 骨架 `fe/mall-h5` 已删除，C 端前台统一为 `fe/mall-shop`；`/shop` 白名单改为逐条「方法+路径」；mall-pc 从浏览版升级为完整购物链路，api 层 7 模块）　后端：`be/mall-server`（com.mall，端口 8431）

## 一图总览

```

mall-shop (9531) ──┘
                     /uploads/**  ──▶ FileWebConfig 静态映射（图片直链，白名单，三端通用）

                                    ├─▶ /system/dict、/loginLog、/system/oper-log（基座）
                                    ├─▶ /file（上传/下载，需登录）
                                    └─▶ /flow（工作流，需登录）
```

## 后端分包（5 类前缀，互不交叉）

| 前缀 | Controller | 包位置 | 鉴权 | 服务对象 |
|---|---|---|---|---|
| `/shop` | ShopXxxController ×7（浏览 / 会员认证 / 购物车 / 订单 / 支付 / 优惠券 / 地址） | `controller/shop/`（前台专用子包） | 逐条「方法+路径」白名单（register、login、banners、categories、goods 免登录），其余需**会员 token** | 商城前台 mall-pc + mall-shop |
| `/mall_*`（12 张业务表） | MallXxxController ×12 | `controller/` | 登录 + 权限点（`MallXxxApiPerms`） | 后台 mall-web |
| `/system/dict`、`/loginLog`、`/system/oper-log` | SysDictController 等 | `controller/`、`system/` | 登录（基座） | 后台 mall-web |
| `/auth`、`/file`、`/flow` | Auth/File/FlowController | `common/auth`、`common/file`、`common/flow` | 白名单(login/captcha) + 登录 | 后台 mall-web |
| `/uploads/**` | —（静态资源映射） | `common/file/FileWebConfig` | 白名单直链 | 三端 `<img>` 标签 |

**分包规则**：
1. 前台买家接口只能加在 `controller/shop/` 包、`/shop` 前缀下。**白名单按「方法+路径」逐条登记**（`AuthContextFilter.SHOP_ANON_LIST`，当前 5 条：会员注册/登录 + banners/categories/goods 三个浏览 GET），不再整前缀放行——V3 的购物车/下单/支付写接口一律要会员 token；`m:` 前缀的会员会话只放行 `/shop/**`，后台 sys token 反过来访问非白名单 `/shop/**` 直接 401，两侧身份不互通。
2. 后台接口保持在 `controller/` 包、`/mall_*` 前缀；新增表走代码生成器，会同时产出 Controller + ApiPerms。
3. `ShopController` 的 VO 在 `dto/ShopGoodsVO`、`dto/ShopSkuVO`——只暴露买家可见字段，与 admin 的 `MallXxxVO` 物理隔离，防止误把 remark/审计字段/成本价透给买家。

## 前端 api 层分包

| 工程 | api 代码位置 | 调用前缀 | 代理链路（vue.config.js） |
|---|---|---|---|
| mall-pc | `src/api/*.js` ×7（shop/auth/cart/order/pay/coupon/address），共用 `utils/request.js`（会员 token 注入 + 401 跳登录） | `/shop` | `/shop`、`/uploads`、`/img` → 直连 8431，不剥前缀（vue.config.js） |
| mall-shop | `src/api/*.js` ×7（shop/auth/cart/order/pay/coupon/address） | 全部 `/shop/**`，经 `baseURL: '/api'` 发出 | `/api` → 剥前缀 → 8431（vite.config.js） |
| mall-web | `src/api/mall_*.js` ×12 + 登录/字典等 | `/api/mall/mall_*`、`/system/*`、`/auth/*` | `/dev-api` → 剥 `^/dev-api(/api/mall)?` → 8431 |

**规则**：前台两个工程的 api 层不允许出现 `/mall_*`、`/auth`、`/file` 任何一个调用；后台 mall-web 不调 `/shop`。跨端复用的只有 `/uploads` 图片直链（img 标签，不算接口调用）。
